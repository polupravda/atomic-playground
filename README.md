# Atomic Playground

An interactive, PhET-inspired atom & chemistry playground for kids. Build
atoms from protons, neutrons and electrons; discover elements; watch decay;
morph shells into probability clouds; form curated molecules. Purely
client-side — no backend, auth, or persistence.

## Run

```bash
npm install
npm run dev
```

## Stack

Vite · React 19 · TypeScript · react-konva (simulation canvas) · Motion ·
Zustand · Radix UI · Tailwind CSS v4
